# 线上部署（直接拉镜像）

整个 `deploy/` 目录是自包含的部署包，拷到服务器就能用。

```bash
cd deploy
cp .env.example .env
# 编辑 .env，把 EXAM_ADMIN_PASSWORD 换成自己的强密码
docker compose up -d
```

浏览器打开 `http://服务器IP:8888/`，用 `.env` 里的管理员账号登录。

## 目录里有什么

| 文件 | 作用 |
|---|---|
| `docker-compose.yml` | 直接拉 `cxsz16888/practiceexam:latest`，不本地构建 |
| `.env.example` | 管理员账号与会话配置模板 |
| `data/exam.db` | **题库本体**，唯一的题目来源；`data/` 目录不要漏带 |

镜像里只有程序和静态资源，**一道题都没有**。空 `data/` 启动会得到 0 道题的站点，首页会提示「当前没有已发布的题库版本」。也不要指望在容器里跑 ETL —— 镜像没装 pandas / openpyxl / xlrd，`etl/` 也没打进去。

`2026-11` 版（active，本次导入的那一批），去重后 **11,450 道**：单选 4,591 / 判断 3,812 / 多选 2,856 / 简答 191。可自动判分 11,259 道，标黄必答 19 道。旧管理模板仅开放「配电安规通用」「配电带电」2 个专业，其余 20 个在考试中停用；练习登录即可访问全部已发布题目，不受专业启用状态或人员授权限制。历史 `legacy` 题库已从运行库移除，原库快照在 `archive/`。

## 练习开放与旧库升级

- 登录及管理页面统一使用「用户名」；原账号不变，登录 API 和导入 CSV 的 `employee_no` 字段继续兼容。
- 首页直接练习，可选全部/指定人员类型，并与真实标签下拉多选、完整来源路径与工作表、题型和随机顺序组合，展示匹配题数。首页另有无需人员授权的自主模拟入口，人员类型自由选，成绩标为非正式。管理场次也不再检查人员授权，但保留模板、专业、场次、名单、时间与次数校验。
- 新代码首次启动按序执行 `0002` 来源关系迁移、`0003` 自主模拟/阈值快照迁移和 `0004` 自由组卷规则快照迁移，并用镜像内不含题干/答案的来源索引补全 2026-11 旧库的多来源信息；后续启动幂等，无需在服务器安装 ETL 或重导原始资料。必须部署包含新增 migration、fixtures 索引和前后端代码的新镜像，仅更新文档不会改变现网行为。
- 升级前做一致性备份，并在副本验证迁移。开发验证未修改本目录的 `data/exam.db`；部署时由新应用对服务器挂载库迁移。详见主 README「练习与考试权限、筛选接口」。本轮不构建、发布或推送镜像。

## 上线前注意

- 两张试卷模板状态仍是 `draft`，**能练习并可自主模拟、不能据此声称正式考试规则**；自主模拟不用激活模板或创建场次。仅管理场次需激活模板并配置场次。首页自主测试已摆脱模板：全部/任一有题人员类别均可随机组卷，题型数量直接填写，匹配库存逐型展示，固定 100 分按题数均分（余数按卷序各补 0.01），时长 5~240 分钟。简答实际入卷且交卷后本人参考自评；自评未全完成时没有最终总成绩，完成后仍为非正式自评成绩，不计管理场次统计。
- `./data` 会持续写入 `-wal` / `-shm`、成绩、导入报告和备份，别删、别只备份单个 `.db` 文件。按主 README 的 `VACUUM INTO` 做一致性备份。
- 要固定版本，把 compose 里 `image` 的 tag 换成已发布的 commit sha（见文件顶部注释）。
- 完全无外网的内网机器：在联网机 `docker pull` 后 `docker save` / `docker load` 分发，改用项目根的 `docker-compose.yml`（本地 build）或给这个 compose 加 `image: practice-exam:本地tag`。
